# data-analytics-journey
Health organisation executive dashboard built with Power BI to analyze patients, visits, revenue, costs, profit, and patient outcomes.
## Task 2 — Patient Analysis

In this phase of the project, I analyzed patient demographics, diagnoses, patient volume, and patient outcomes.

### Key Analysis
- Patients by Age Group
- Male vs Female Patients
- Patients by Diagnosis
- Patients by State
- New vs Returning Patients
- Average Visits per Patient
- Patient Outcomes

### Tools Used
- Power BI
- DAX
- Excel

### Objective
The goal was to understand who the patients are, identify common diagnoses, analyze patient volumes across states, and understand patient outcomes.
